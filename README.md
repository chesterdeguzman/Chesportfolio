## Deployment

Designed for **GitHub Pages**.

1.  Push the repository to GitHub.
2.  Go to **Settings → Pages**.
3.  Select **Deploy from branch**.
4.  Choose the **main** branch and **/(root)** folder.

Your portfolio will be available at:
